# Student Management System

A beginner-friendly Student Management System built in C.

## Project Description

This is a console-based application developed using the C programming language to manage student records.

The system allows users to add, display, search, update, and delete student information. It also calculates student averages and grades and provides class statistics.

## Features

- Add student details
- Display all students
- Search student by ID
- Update student details
- Delete student records
- Calculate subject average
- Calculate student grade
- Display student statistics
- Validate student ID, age, and marks
- Prevent duplicate student IDs
- Save student records to a file
- Load saved records when the program starts

## C Concepts Used

- Structures
- Arrays
- Functions
- Loops
- Conditional statements
- File handling
- Input validation
- CRUD operations
